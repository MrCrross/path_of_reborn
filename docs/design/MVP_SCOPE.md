# MVP SCOPE

## Цель

Собрать vertical slice, который доказывает связку «вступление → фэнтезийный бой → добыча → экипировка → Checkpoint → сохранение» на одном телефоне.

## Входит в MVP

| Система | Минимальный результат | Готово, когда |
|---|---|---|
| Prologue | Вступительная последовательность с переходом в игру | сцена проходит от начала до title card без тупиков |
| World screen | Одна фэнтезийная локация и маршрут первой главы | игрок понимает цель и следующую точку |
| Combat | Один герой, 2–3 обычных монстра, базовая атака и уклонение/защита | бой повторяем, проигрыш и победа определены |
| Character | HP, основной stat, уровень и один выбор улучшения | состояние видно и сохраняется |
| Loot | Награда после боя с редкостью и сравнением | предмет можно принять, надеть или отправить в inventory |
| Inventory | Сетка/список предметов, фильтр по типу, equip/unequip | состояние не теряется при переходах |
| Checkpoint | Установка/активация точки и восстановление после поражения | правила явно показаны игроку и покрыты smoke test |
| Save | Один локальный профиль | закрытие и повторный запуск восстанавливают прогресс |

## Не входит

Сетевая игра, кланы, гильдии, мировые боссы, PvP, клановые события, торговая площадка, серверная авторизация, сложная процедурная генерация, десятки классов и биомов.

## Порядок прототипирования

1. Технический portrait viewport и переходы сцен.
2. Состояние игрока, один бой и локальная победа/поражение.
3. Добыча, inventory и экипировка.
4. Checkpoint и восстановление.
5. Prologue blockout и локальное сохранение.
6. Только после этого — замена blockout на утверждённые pixel-art assets и баланс.

## Метрики slice

Проверить на трёх portrait-разрешениях: читаемость текста и кнопок, время первого понятного действия, отсутствие потери состояния после поражения, стабильность 30/60 FPS на целевом Android и корректный импорт всех утверждённых assets.
