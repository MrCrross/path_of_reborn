# Path of Reborn

# Диалоги и игровые подсказки

**Версия:** 2.0  
**Язык:** русский  
**Назначение:** scene-by-scene dialogue script и tutorial copy для MVP

## Правила разметки

- `DIA_*` — реплики диалогов и внутреннего монолога.
- `TUT_*` — интерфейсные подсказки, не произносимые персонажами.
- `Trigger` — условие показа; `Once` — однократный показ в текущем профиле.
- Все сюжетные разговоры линейны: игрок только продолжает чтение. Вариантов ответа, выбора вопросов и альтернативных реплик нет.
- Реплики NPC после возвращения восстанавливаются по состоянию Checkpoint, если отдельно не указано иное.
- Anime 2D-портреты используют эмоциональные теги только как производственные указания, не как текст для озвучивания.

# Scene 01 — Crosswalk

## Characters

Харуто Куросава; Юи; водитель грузовика без реплик; фоновые прохожие.

## Context

Вечерний Токио. Харуто идёт домой после поздней смены. Юи ждёт зелёный сигнал и смотрит в телефон. Грузовик приближается, водитель отвлечён.

## Dialogue

**DIA_INTRO_001 — Харуто / мысли:**  
— Десять часов сорок две минуты. Если лечь сразу, получится почти шесть часов сна. Почти — это уже оптимизм.

**DIA_INTRO_002 — Харуто / мысли:**  
— Мама написала. Отвечу дома. Дома будет тише. Дома будет… позже.

**DIA_INTRO_003 — Харуто / мысли, при появлении грузовика:**  
— Слишком быстро. Он вообще видит переход?

**DIA_INTRO_004 — Харуто:**  
— Эй! Стой! Там машина!

**DIA_INTRO_005 — Харуто / мысли:**  
— Ноги? Сейчас было бы очень удобно вспомнить, зачем вы нужны.

**DIA_INTRO_006 — Харуто / мысли, перед броском:**  
— Ремешок. Могу дотянуться. Хотя бы до ремешка.

**DIA_INTRO_007 — Харуто / мысли, после толчка:**  
— Хоть раз… успел.

**DIA_INTRO_008 — Харуто / мысли, в затемнении:**  
— Я всё собирался потом. Позвонить. Съездить. Начать. Как будто у «потом» нет предела.

**DIA_INTRO_009 — Харуто / мысли:**  
— Мама написала… Надо было не «когда будет минута». Просто позвонить.

## Internal monologue

Внутренний монолог включён в основные ID. В сцене нет отдельных шуток после удара. Между `DIA_INTRO_008` и `DIA_INTRO_009` оставить паузу для приглушённых звуков города.

## Gameplay hints

`TUT_STORY_001`  
> Коснитесь экрана, чтобы продолжить.

`TUT_STORY_002`  
> Проведите взглядом к дороге: коснитесь отмеченной области.

`TUT_STORY_003`  
> Удерживайте, чтобы сделать шаг вперёд.

## Conditions

`Trigger: начало нового профиля → DIA_INTRO_001`  
`Trigger: первый показ телефона → DIA_INTRO_002`  
`Trigger: грузовик входит в кадр → DIA_INTRO_003`  
`Trigger: включение зелёного сигнала → DIA_INTRO_004`

`Trigger: затемнение после удара → DIA_INTRO_008–009`  
`Once: все tutorial-подсказки сцены`

**DIA_GODDESS_029 — Мицуки:**

**DIA_GODDESS_031 — Харуто:**

**DIA_GODDESS_032 — Харуто / мысли:**

## Общие условия локализации

- Не разделять ID реплики и её текст; изменения смысла требуют новой версии строки.
- Сохранять различие «астра» / «Кристалл Эха» / «Отголосок».
- Не переводить мета-названия даров как местные термины NPC: Адаптация, Эхо Мастерства, Чекпоинт и Инвентарь используются преимущественно Мицуки, Харуто и UI.
- Не добавлять варианты ответа, A/B/C-реплики или разные тона одного сюжетного разговора.
- В репликах Акари не добавлять смягчающие частицы, если их нет в русском исходнике.
- Внутренний монолог маркировать отдельно от озвученной речи.
- Подсказки должны помещаться в две короткие строки portrait UI; более длинные правила выносятся в справочник.
