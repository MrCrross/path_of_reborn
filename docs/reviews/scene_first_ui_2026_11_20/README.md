## Проверки

- Headless домен и UI-контракты: `tests/test_runner.gd` — **55/55** кейсов.
- Headless GUI-раскладка: `tests/ui_layout_runner.gd` — **663/663** проверки на 180×320, 180×400, 195×422, 206×458. Включая новое: отсутствие угловых панелей HP и карточки встречи; resolver не тикает и ввод игнорируется до конца появления врага; двойной тап запускает одну встречу; повторы доступны; полосы HP строго над головами при всех размерах окна.
- Кадры выше — реальный запуск проекта (изолированный `--save-path=user://mcp_scene_review.cfg`, основной профиль не тронут).

## Не проверено

- Физический Android: размеры зон касания (рекомендация 48dp ≠ 48 logical px), читаемость полосы 36×4 и чисел 7pt на экране устройства, FPS.
- Гипотезы бюджета площади подложек (15% путь / 20% бой) не замерялись инструментально.
- Длинные имена врагов: текущая база короткая, полоса фиксированной ширины не растягивается именем (регрессия не выявлена).
