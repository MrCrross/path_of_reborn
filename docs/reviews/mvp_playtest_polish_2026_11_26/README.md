# Правки по плейтесту первой главы · 26 ноября 2026

## Изменения

- В Роще у иглопсов читаются волчьи морды, лапы и иглы. Мотылёк раскрывает крылья, а плетун вытягивает один из двух побегов. Новый лунный лён выделяется на золотой траве. После сбора интерфейс выделяет оставшийся маркер. После осмотра обеих целей появляются возврат в Лиорен и Печать.
- Акари и Харуто близки по росту на одном плане. Три новые иллюстрации показывают встречу, совместный удар и разговор о ключе. У Акари новые кадры стойки, выпада и огненной печати. Фоны поста, Оврага и эпилог о письме экспортированы из исходников в 540×960. Сидзука видна при своём предупреждении, а Дайдзиро занимает центр кадра в своём разговоре.
- На второй слизи Тропы первый «Точный удар» запускает игрок. Больше здоровья у пар Рощи, щитня и грызунов Оврага. Перед верхней площадкой доступна Печать. Жаба наносит две атаки подряд и открывает броню после прыжка. На основном маршруте без повторов уровни 3 и 4 приходятся на сдачу Рощи и Оврага. Для уровня 5 нужен дополнительный опыт.
- В лавке товары прокручиваются внутри отдельной рамки. Длинные имена переносятся внутри строки. Прут странника стоит две медные астры. Оснащённый прут виден с указанием снять его, а старые записи прута получают цену при загрузке. Подтверждения используют вертикальные кнопки. В диалогах увеличены внутренние отступы.

## Арт

Исходники и точные промпты встроенного ImageGen сохранены локально в `art_working/mvp_playtest_polish/`. Спрайты приведены к прозрачным ячейкам с опорами, сюжетные кадры — к 540×960. 23 обновлённых файла проверены по размеру, спрайты также по альфа-каналу. Точные источники и контрольные суммы перечислены в [манифесте](../../../assets/manifest.json). В игре используются копии из `game/art/`.

Темп и сложность для нового игрока требуют отдельного плейтеста на физическом телефоне.

Кадры, отчёты и подписанный APK лежат локально в `art_working/mvp_playtest_polish/`. Отладочный APK использует пакет `com.pathofreborn.game`. Подпись APK проверена через `apksigner`.

```powershell
$env:APPDATA = (New-Item -ItemType Directory -Force 'art_working/mvp_playtest_polish/profile').FullName
python tools/copy_art.py
godot --headless --path game --import
godot --headless --path game --script res://tests/test_runner.gd
godot --headless --path game --script res://tests/ui_layout_runner.gd
godot --headless --path game --script res://tests/animation_assets_runner.gd
godot --path game --fixed-fps 60 --disable-vsync --script res://tests/chapter_acceptance_runner.gd -- --chapter-out=res://../art_working/mvp_playtest_polish/windows
godot --path game --fixed-fps 60 --disable-vsync --script res://tests/hollow_acceptance_runner.gd -- --hollow-out=res://../art_working/mvp_playtest_polish/hollow_windows
godot --headless --path game --export-debug Android "$PWD/art_working/mvp_playtest_polish/path_of_reborn_playtest_debug.apk"
```

## Катсцены Края Ветров

Для NAR-15, NAR-16 и NAR-17 опорой стал ракурс первой встречи. Башня, арка, знамёна, Печать, горы и площадка сведены к одному фоновому слою. Персонажи и сюжетные эффекты собраны поверх него. Харуто остаётся слева, Акари справа. В боевом кадре Акари держит прямое двузубое копьё, а на наплечнике дозорного убран прицел. Промпты ImageGen, фон, прозрачные слои и сборка кадров хранятся локально в `art_working/winds_edge_continuity/`. Источники и контрольные суммы внесены в [манифест](../../../assets/manifest.json).

Сверены размеры 540×960, копии в `game/art/` и попиксельное совпадение открытых участков башни, флага и переднего плана. Сквозной прогон на изолированном профиле прошёл 289/289 проверок. Все три кадра сняты в окнах 360×640, 360×800, 390×844 и 412×915. Оконные кадры и общий предпросмотр лежат в `art_working/winds_edge_continuity/`.

Обновлённый отладочный APK там же, под именем `path_of_reborn_winds_edge_debug.apk`. `apksigner` подтвердил подписи v2 и v3 и совпадение сертификата с предыдущим APK. Проверка этих кадров выполнена в оконном режиме Godot.
