## Каталог и карточка персонажа

Каталог показывает доступных по сюжету персонажей, их уровни, ожидающие улучшения и общую мощность. Карточка Харуто использует полнофигурный спрайт странника. Экипировка стоит по бокам, нажатие на предмет открывает модальное окно с параметрами и действием для предмета. Верхняя левая стрелка возвращает к выбранной плитке каталога. Кнопка улучшений на Тропе открывает карточку Харуто сразу. [Каталог](characters_360x640.png) · [Харуто](character_profile_360x640.png) · [Карточка предмета](character_item_360x640.png)

Следующий уровень даёт один выбор между Силой и максимальным HP. Прогноз учитывает данные героя, модификаторы комплекта и округление от Следов. Способности указываются по уровню открытия. На максимальном уровне остаются доступными накопленные выборы.

Пробная формула мощности для интерфейса — `макс. HP + 4 × Сила + 4 × Защита + 2 × Мана`. Используются итоговые параметры с экипировкой и фамильяром. Каталог суммирует оценки доступных героев. Формула применяется только при отображении.

Тестовый дорожный спутник использует пиктограмму раздела до появления утверждённого изображения. После обновления прошли 90 игровых тестов, 1530 проверок компоновки и 54 оконные проверки в четырёх портретных размерах. На устройстве Android экран не проверяли.
