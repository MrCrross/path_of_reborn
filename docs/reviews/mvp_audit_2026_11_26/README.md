# Аудит MVP · 26 ноября 2026

Проверка охватила пролог, Тропу, Лиорен, торговлю с Дайдзиро, Гильдию и первое задание Рощи. Каждый прогон использовал изолированный профиль.

## Исправления

| Сценарий | Ошибка | Результат |
| --- | --- | --- |
| Подход и парные встречи | Реплики о двух иглопсах играли на пустой тропе. Правый иглопёс обрезался краем кадра, плетун смещался относительно своей полосы HP. | Иглопсы видны до боя. Постановка превью и боя использует общие опоры. Все кадры обеих пар целиком помещаются в игровую область, полосы HP остаются над силуэтами. |
| Выбор цели | Касание видимого края монстра могло попасть мимо области выбора. Удар по дальней цели было трудно связать с её реакцией. | Учитывается ширина корпуса, полосы HP остаются отдельными целями. Ручной бой подсказывает, как переключить цель. Эффект контакта появляется на цели, зафиксированной в начале замаха. |
| Помощь Кэнте | После разговора выбор появлялся на обычной тропе, где Кэнты нет. Кнопка улучшений занимала место над вариантами ответа. | Иллюстрация моста остаётся на время выбора. Статусы освобождают лицо Кэнты. Улучшения доступны через рюкзак с индикатором. |
| Поляна | Прозрачный контейнер перехватывал касания по льну и маркеру. Реквизит был крупнее исходной пиксельной сетки, собранный лён оставался полупрозрачным. | Реквизит можно нажать на сцене или активировать кнопкой. Лён исчезает после успешной записи, осмотренный маркер остаётся с тремя насечками. Поле касания льна сохраняет минимум 24 логических пикселя. |
| Выход из Рощи | Горячие клавиши могли открыть рюкзак или Печать поверх подтверждения. После отказа записи в конце реплики об уходе оставалась кнопка завершённого диалога. | Подтверждение блокирует фоновые команды. После отказа записи фокус получает «Повторить выход». Прочитанная в текущем сеансе реплика не мешает повторить запись выхода. |
| Лавка Дайдзиро | Верхняя строка каталога перекрывала лицо торговца, а на высоком экране пересекала его руки. | Каталог начинается под прилавком. Строка прокручивается в видимую область при получении фокуса. Проверены все четыре направления обмена. |
| Гильдия | При обеих выполненных целях карточка показывала только выдачу задания. Повторный выход в Рощу и сдача выглядели одинаково важными. | Карточка сообщает о готовности к сдаче. Кнопка отчёта выделена цветом и получает начальный фокус. |

Сюжетные варианты, награды и пороги баланса сверены с [планом Рощи](../../design/MVP_WHISPERING_GROVE_PLAN.md). Границы записи для бинта, наград, Печати и сдачи задания проверены через отказ записи, повтор и загрузку профиля.

Набор анимаций проверил стойки с веткой, с мечом и без оружия. [Предыдущий Android-прогон лавки](../merchant_stage_2026_11_22/README.md#android-эмулятор-anixart-api35-23-ноября)

$env:APPDATA = (New-Item -ItemType Directory -Force 'art_working/mvp_audit/profile').FullName
python tools/copy_art.py
godot --headless --path game --import
godot --headless --path game --script res://tests/test_runner.gd

## Android

Подписанный debug APK на Godot 4.7.2 проверен на изолированном эмуляторе Android 15, 1080×2400, GPU host. Прогон начинался с профиля после регистрации в Гильдии. Системный Back закрыл диалог подхода и отменил подтверждение выхода. Штатными касаниями пройдены два автобоя и помощь Кэнте. После перезапуска «Продолжить» открыло ожидающие итоги второго боя. Касания по объектам записали лён и маркер, после чего лён исчез, а на маркере появились насечки.

Выход без ручной точки сохранил обе цели. После сдачи и перезапуска Гильдия показала завершённое задание, а кошелёк содержал 35 серебряных астр. В лавке список появился под прилавком. Добровольный разговор открылся касанием и закрылся по Back. [Кадры Android](android.png)

Проверка на физическом Android и человеческий playtest остаются открыты.
