## Воспроизведение

Из корня репозитория с Godot 4.7.2 в PATH. Оконные сценарии создают свои профили и записывают проверочные кадры локально.

```powershell
godot --headless --path game --import
godot --headless --path game --script res://tests/test_runner.gd
godot --headless --path game --script res://tests/ui_layout_runner.gd
godot --headless --path game --script res://tests/animation_assets_runner.gd
godot --path game --fixed-fps 60 --disable-vsync --script res://tests/chapter_acceptance_runner.gd -- --chapter-out=res://.godot/refactor_review/chapter
godot --path game --fixed-fps 60 --disable-vsync --script res://tests/guild_orders_acceptance_runner.gd
godot --path game --fixed-fps 60 --disable-vsync --script res://tests/hollow_acceptance_runner.gd -- --hollow-out=res://.godot/refactor_review/hollow
```

В изолированной среде сборка Steam сообщала о доступе к системным сертификатам и глобальным настройкам редактора. Импорт и проверки завершились успешно. Эргономика на физическом телефоне, заметность подсказок в первом бою и влияние на погружение остаются вопросами для плейтеста с игроками.
