## Воспроизведение отказа записи

Запуск Godot 4.7.2, Windows Compatibility, с отдельным `--save-path=user://por_scene_reaudit_<id>/profile.json` во временном каталоге. Сценарий открывал реальные экраны `GameRoot` и вызывал их обработчики; 299 из 300 тиков фиксации прокручивались в тесте.

1. Создать профиль, пропустить пролог и открыть Печать. Занять путь `profile.json.tmp` пустым каталогом. Начать фиксацию, дождаться 300-го тика. В памяти одна ручная точка, на диске ноль. `SetFx` видим, фокус отсутствует, уведомление содержит ошибку временного файла.
2. Убрать каталог-блокировку, начать бой и сдаться. Теперь согласованный профиль на диске содержит состояние возврата, одну ручную точку и доступный «Первый след». Снова заблокировать `.tmp`, подтвердить «Первый след». В памяти ожидаемый возврат снят, ручных точек ноль, «Первый след» потрачен, открыт экран World. Чтение файла показывает ожидаемый возврат, одну ручную точку и доступный «Первый след». Это два снимка одного профиля до и после неуспешной операции. Блокировка снята в конце проверки.

Удаление точки следует похожему пути `mutate → changed → autosave`. Отдельный отказ при удалении предстоит покрыть регрессией.

## Проба источника пролога

Сравнение сделано в одном окне `720×1280`. Во втором кадре временно заменена только `ShotFrame.texture`. Размер окна, текст, панель и фильтрация совпадают. Из большого исходника возвращаются лицо, детали одежды и перспективные линии улицы. Исходник заметно ближе к рисованной иллюстрации, поэтому итоговую плотность пикселей следует подобрать на паре кадров и проверить переход Токио → переход → Порог. Пробная текстура использована только в диагностическом кадре. [Оригинал по манифесту](../../../art_working/nar_tokyo_prologue_p1_2026_11_18/nar_01_v02/source/haruto_tokyo_evening_story_v02.png) · [Рекомендации Godot по разрешению](https://docs.godotengine.org/en/4.7/tutorials/rendering/multiple_resolutions.html)

Рендер проверен в окнах `360×640` и `720×1280`. HUD-фикстура выставила частичное HP обеих сторон. Оригинальные PNG, GDScript, сохранения пользователя и предыдущие отчёты использовались в режиме чтения. При запуске графического процесса отдельно появилось предупреждение окружения о хранилище корневых сертификатов Windows. Android, реальный тач, вырезы, производительность в новых ассетах и вся последовательность пролога на устройстве остаются открытыми.
