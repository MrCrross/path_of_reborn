# UX/UI после правок — 2026-11-19

Кадры состояния игры после UX/UI-итераций по `docs/design/UX_UI_AUDIT_2026_11_19.md` и промпту `docs/design/KIMI_UX_UI_REWORK_PROMPT.md`. Исходные «до»-кадры: `../ux_ui_2026_11_19/` (не перезаписывались).

## База отображения

- Viewport проекта: 180×320 logical px, stretch `canvas_items`, scale 2 (integer), фильтрация `nearest`.
- Скриншоты сняты из запущенной игры (managed process, held) при окне 360×640: viewport 180×320, scale 2, offset (0,0).
- Проверенные окна (фактические данные от input-инструментов):
  - 360×640 → viewport 180×320, scale 2, offset (0,0)
  - 390×844 → viewport 180×320, scale 2, offset (15,102)
  - 412×915 → viewport 180×320, scale 2, offset (26,138)
  - 360×800 → viewport 180×320, scale 2 (letterbox, как 360×640)
- На всех размерах layout стабилен (поля letterbox пустые). Использование высоты тall-экранов — открытый вопрос.

## Примечания

- Debug-панель в кадрах отсутствует: видна только при явном `--debug-ui`.
- Физический Android не проверялся; desktop synthetic touch ≠ Android-приёмка (48×48 dp, системные жесты — открытый вопрос).
- Звукового оформления нет — отдельный art gap.
