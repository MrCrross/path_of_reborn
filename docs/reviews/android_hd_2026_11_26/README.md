# Android-релиз и переход на рисованную графику

26 ноября 2026, Godot 4.7.2, изолированный Pixel 6 AVD с Android 15 API 35 и окном 1080×2400. Проверка выполнена касаниями через `adb`. На физическом устройстве сборку ещё не запускали.

## Вёрстка и экспорт

В исходном `path_of_reborn_release.apk` первая реплика отсутствовала на экране, а «Спасти» появилась у верхнего края. Все 19 файлов данных для нарратива, маршрутов, магазина и атласов присутствовали. Сбой возникал после переноса узлов из `MarginContainer` с сохранением уже рассчитанной позиции. Теперь `SafeOverlay` объявлен в сцене, а панель и действие имеют нижние привязки с первого расчёта вёрстки. Фильтр экспорта явно включает JSON, доступные через `FileAccess`.

Новый APK устанавливается через `adb install -r` поверх исходного тестового релиза с тем же сертификатом. APK содержит `arm64-v8a` и `x86_64`. Прогон проверяет сохранение позиции пролога, «Спасти», реплики Харуто и Мицуки, предбоевой диалог, награду и карточку предмета.

## Графика и карточки

Восемь локаций получили перерисованные фоны с прежней постановкой. Кадры пролога, предметы, персонажи и анимации обновлены по доступным мастерам. Для моховой слизи, стойки Дозорного и эффекта Печати подготовлены новые рисованные версии. Навигационные пиктограммы используют гладкие контуры, а эффект предупреждения о зоне удара — сглаженную дугу. Мастера и полные промпты ImageGen лежат локально в `art_working/android_hd_2026_11_26/masters/`. Размеры, источники и хеши находятся в [манифесте](../../../assets/manifest.json).

В рюкзаке теперь три колонки, у добычи увеличены зона касания и иллюстрация, карточки подробностей занимают больше экрана. Уменьшен размер текста реплик и общих подтверждений. Подробности и подсказки остаются доступны через прежние действия.

## Воспроизведение

```powershell
python tools/copy_art.py
godot --headless --path game --editor --import
godot --headless --path game --script res://tests/test_runner.gd
godot --headless --path game --script res://tests/ui_layout_runner.gd
godot --headless --path game --script res://tests/animation_assets_runner.gd
godot --path game --fixed-fps 60 --disable-vsync --script res://tests/chapter_acceptance_runner.gd
godot --headless --path game --export-release Android "$PWD/art_working/android_hd_2026_11_26/path_of_reborn_release_hd.apk"
adb -s emulator-5580 install -r "$PWD/art_working/android_hd_2026_11_26/path_of_reborn_release_hd.apk"
```

Прошли 111 доменных тестов, 1675 проверок компоновки, 466 проверок анимаций и 289 проверок главы в окнах 360×640, 360×800, 390×844 и 412×915. В Android-эмуляторе использовано аппаратное ускорение GLES. Экспорт и рабочие снимки находятся локально в `art_working/android_hd_2026_11_26/`.

## Стрелка, настройки и боевой навык

- Маркер пролога содержит `TextureRect` размером 16×16 с `EXPAND_IGNORE_SIZE`. Так импорт SVG при масштабе 4× не меняет размеры стрелки или мишени. `AppTheme` задаёт шаги 4, 8 и 12 логических px для компактных промежутков, внутренних полей и расстояния между секциями. Настройки используют эти шаги и сохраняют области касания от 24 логических px.
- «Точный удар» остаётся после обучения. Урон и восстановление берутся из `AbilityDefinition`. В ручном бою навык использует общее окно атаки. При ручном навыке в автобое нажатие во время обычной атаки заменяет следующий удар навыком. Пауза останавливает боевые тики. Полный автобой сохраняется по умолчанию и для старых настроек. Это сохраняет проверенный баланс, в том числе победу над Хрустальной жабой. Переключатель действует со следующего боя и хранится в настройках вне Печати Пути.
- Реплика об оценке использует название из `ItemDefinition`, аспект и цену за единицу из продаваемого экземпляра. Рекомендация куртки использует `GameSession.shop_offers()`, как каталог лавки.
