# Роща Шелестящих Трав · проверка этапа

Сборка на Godot 4.7.2, Compatibility, 22 ноября 2026. Оконный сценарий начинает с изолированного профиля после регистрации ранга E и идёт из города через Гильдию до подтверждённой сдачи. [План этапа](../../design/MVP_WHISPERING_GROVE_PLAN.md)

[Повторный аудит от 26 ноября](../mvp_audit_2026_11_26/README.md) фиксирует исправления, свежие кадры и проверки перед коммитом.

## Маршрут, сохранение и баланс

- GameSession берёт пары, очередность, задержки и награды из [данных маршрута](../../../game/data/route/whispering_grass_grove.json). У двух иглопсов отдельные экземпляры. Автобой начинает с первого слота, после победы над целью переходит к следующей. В ручном бою выбор следующей цели доступен касанием. Контакт текущего замаха привязан к цели, выбранной при его начале.
- Начальные параметры для playtest. Шум задерживает первую подготовку иглопса на 12 тиков и сближает окна уклонения. При попадании пыльца на 90 тиков замедляет начало следующего замаха и его перезарядку на 50%. Пыльца не снимает HP. Плетун наносит обычный урон отдельно.
- Первая встреча даёт 6 XP, две иглы и один бинт. Вторая даёт 8 XP и склянку пыльцы. Лён и осмотр хранятся как две вехи задания. Карта отображается на карточке Гильдии. Сдача даёт 8 XP, 35 серебряных астр и два Эхо за первый отчёт. Обычные награды и «Точный выпад I» восстанавливаются вместе с профилем Печати, а начисленные однажды Эхо и прочитанные реплики остаются в памяти. Множитель «Точного выпада I» — ×1,25 для контакта существующего умения в фазе уязвимости. Реплика об уровне 3 зависит от уровня до и после записи отчёта.
- Обычный и исторический v7 используют тот же DTO. Grove хранит откатываемые вехи в существующих словарях профиля. Результат пары использует новый режим в существующем pending-результате. SaveService сверяет его с локацией и текущей вехой. Профили предыдущей версии игры читаются без миграции.
- ENV-14 и NAR-13 переэкспортированы в 540×960 из проверенных мастеров 941×1672. В runtime подключены утверждённые спрайты, реквизит и семь существующих листов с 28 кадрами. Многострочные атласы читаются построчно, кадр угрозы следует фазе resolver. [Происхождение и хеши](../../../assets/manifest.json)

```powershell
$env:APPDATA = (New-Item -ItemType Directory -Force 'art_working/grove_test_profile/local').FullName
python tools/copy_art.py
godot --headless --path game --import
godot --headless --path game --script res://tests/test_runner.gd
godot --headless --path game --script res://tests/ui_layout_runner.gd
godot --headless --path game --script res://tests/animation_assets_runner.gd
godot --path game --fixed-fps 60 --disable-vsync --script res://tests/grove_acceptance_runner.gd
```

## Android и playtest

26 ноября 2026 сквозной прогон прошёл на чистом изолированном Android 15 (API 35, x86_64, 1080×2400) в debug APK Godot 4.7.2. Ввод подавался через `adb input tap` и системный Back. Back закрыл диалог подхода, а «Продолжить» вернуло к реплике. Касаниями пройдены оба автобоя, помощь Кэнте бинтом, сбор льна, осмотр маркера, пятисекундная фиксация Печати и сдача Мидори.

Перезапуск перед получением награды второй пары восстановил итог боя. Перезапуск после сдачи восстановил карточку «Задание завершено», обе цели и баланс 35 серебряных астр. Ручной выбор цели проверен сенсорным событием в оконном прогоне. [Кадры Android](android_route.png)

Человеческий playtest и проверка на физическом Android остаются открыты.
