# Production assets

Пакет P0/P1 утверждён 19 ноября 2026. В нём 138 именованных PNG каталога и 52 спрайт-листа с 192 кадрами. Файлы распределены по `characters`, `enemies`, `equipment`, `environments`, `ui` и `effects`. Сюжетные кадры лежат в `environments/story`, объекты — в `environments/props`, спрайт-листы — в подпапках `animations`.

[Манифест](manifest.json) содержит статус каждого файла, SHA256, размер, связи с исходниками и промптами и, для анимаций, порядок областей атласа и pivot. Ранние клипы собраны из тех же кадров без изменения их пикселей. Исходники, промпты и референсы хранятся в рабочих папках. Материалы Path of Kings хранятся отдельно как референсы проекта.

Все 190 PNG импортированы в отдельный проверочный проект Godot 4.7.2 с nearest, integer scaling, lossless и выключенными mipmaps. Сверены пиксели и все 192 области `SpriteFrames`. [Отчёт импорта](../art_working/production_review/approved_import.json).
