# Path of Reborn

Оригинальная мобильная Fantasy RPG с элементами Isekai и 2D pixel art (портретная ориентация, Android). В репозитории — играбельный прототип на Godot: пролог, бои со слизью и гоблином, добыча, экипировка, инвентарь, ручной Checkpoint и продолжение игры после перезапуска через `Continue`. Игровые сцены пока используют черновую графику; утверждённый арт-набор лежит в [assets/](assets/README.md) и подключается отдельно. Тестирование на Android-устройстве предстоит.
