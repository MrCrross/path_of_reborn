# Path of Reborn

Оригинальная мобильная Fantasy RPG с элементами Isekai и рисованной 2D-графикой в anime-стиле (портретная ориентация, Android). В Godot доступна первая глава от пролога до эпилога в Лиорене. В неё входят бои, добыча, экипировка, торговля, три задания Гильдии, ручной Checkpoint и продолжение после перезапуска. Runtime использует утверждённый арт из [assets/](assets/README.md). На Windows пройдена вся глава, на Android-эмуляторе проверен жизненный цикл приложения. [Отчёт о приёмке](docs/reviews/mvp_chapter_acceptance_2026_11_26/README.md)
